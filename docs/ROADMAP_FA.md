## فاز ۴ — محصول تجاری

| موضوع | کار |
|---|---|
| مقررات | بررسی با مشاور regulatory: آیا TGA این نرم‌افزار را Medical Device (SaMD) می‌داند؟ |
| نصب | نصب‌کننده‌ی امضاشده (code signing certificate)، به‌روزرسانی خودکار |
| Backend | حساب داروخانه، چند ایستگاه، توزیع امن مدل، پشتیبان Audit |
| اتصال | ورود پروفایل مستقیم از نرم‌افزار بسته‌بندی (FRED، Minfos، Z Dispense…) |
| امنیت | ورود داروساز با PIN، پشتیبان رمزگذاری‌شده، تست نفوذ |
| کسب‌وکار | بیمه‌ی مسئولیت، قرارداد و شرایط استفاده، قیمت‌گذاری و پشتیبانی |

## ریسک‌های اصلی

1. **داده:** بدون دیتاست تأییدشده‌ی داروساز، هویت دارو ممکن نیست.
2. **False Acceptance:** هر قبول اشتباه ریسک بالینی دارد؛ به همین دلیل همه‌ی پیش‌فرض‌ها محافظه‌کارانه‌اند.
3. **مقررات:** طبقه‌بندی TGA می‌تواند زمان و هزینه‌ی ورود به بازار را تغییر دهد.
4. **مخزن عمومی:** اگر این مخزن public است، برای انحصار کامل آن را private کنید (Settings ← General ← Danger Zone ← Change visibility). مخزن قدیمی `avavision` هم کد AGPL دارد؛ آرشیو یا private شود.
