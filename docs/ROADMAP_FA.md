## فاز ۴ — محصول تجاری

| موضوع | کار |
|---|---|
| مقررات | بررسی با مشاور regulatory: آیا TGA این نرم‌افزار را Medical Device (SaMD) می‌داند؟ |
| حریم خصوصی | ارزیابی Privacy Act 1988 و APPs؛ سیاست نگهداری داده |
| Backend | حساب داروخانه، دستگاه‌ها، توزیع امن مدل (Model Registry)، پشتیبان Audit |
| اتصال | ورود پروفایل از نرم‌افزار بسته‌بندی (FRED، Minfos و…) به‌جای ورود دستی |
| امنیت | قفل اپ (Face ID/کد)، رمزگذاری Audit، تست نفوذ |
| انتشار | Apple Developer Program به نام شرکت، TestFlight، App Store یا توزیع Enterprise |
| کسب‌وکار | بیمه‌ی مسئولیت، قرارداد و شرایط استفاده، قیمت‌گذاری و پشتیبانی |

## ریسک‌های اصلی

1. **داده:** بدون دیتاست تأییدشده‌ی داروساز، هویت دارو ممکن نیست.
2. **False Acceptance:** هر قبول اشتباه ریسک بالینی دارد؛ به همین دلیل همه‌ی پیش‌فرض‌ها محافظه‌کارانه‌اند.
3. **مقررات:** طبقه‌بندی TGA می‌تواند زمان و هزینه‌ی ورود به بازار را تغییر دهد.
4. **مخزن عمومی:** این مخزن public است. برای انحصار کامل آن را private کنید (Settings ← General ← Danger Zone ← Change visibility). مخزن قدیمی `avavision` هم کد AGPL دارد؛ آرشیو یا private شود.
