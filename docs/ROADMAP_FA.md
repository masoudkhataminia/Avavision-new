# نقشه‌ی راه تا محصول تجاری

## انجام‌شده (این مخزن)

- [x] بازنویسی کامل بدون وابستگی به کد AGPL
- [x] هسته‌ی منطق با قوانین ایمنی و تست خودکار
- [x] اپ iOS: کاتالوگ، پروفایل، عکس‌برداری، نتیجه، امضای داروساز، Audit زنجیره‌ای
- [x] Release Gate برای مدل و ابزار ارزیابی Holdout
- [x] CI روی Linux و macOS

## فاز ۱ — PackCheck شمارشی روی ایستگاه (کار بعدی)

- [ ] ساخت ایستگاه ثابت (پایه، نور، iPhone مشخص)
- [ ] اندازه‌گیری Webster-pak واقعی و کالیبراسیون Layout در اپ
- [ ] کالیبراسیون آستانه‌های کیفیت تصویر روی ایستگاه
- [ ] جمع‌آوری ۳۰۰+ عکس و آموزش مدل شمارشی (`pill`، `broken`، `foreign`)
- [ ] اجرای سناریوهای پذیرش [راهنمای تست](TESTING_GUIDE_FA.md)

**Gate:** روی Holdout هیچ خانه‌ی خطادار «Count OK» نشود.

## فاز ۲ — هویت دارو

- [ ] انتخاب ۲۰ تا ۵۰ داروی پرمصرف
- [ ] دیتاست هویت با تأیید داروساز (۵۰+ نمونه‌ی Holdout برای هر دارو)
- [ ] آموزش و ارزیابی؛ عبور از Release Gate
- [ ] شواهد تکمیلی (رنگ، شکل، Imprint) در صورت نیاز

## فاز ۳ — Pilot در داروخانه (Shadow Mode)

- [ ] اجرای موازی: داروساز طبق روال عادی بررسی می‌کند و نتیجه‌ها مقایسه می‌شوند
- [ ] اندازه‌گیری False Acceptance و نرخ Review در شرایط واقعی
- [ ] بازخورد UX از داروسازها

## فاز ۴ — محصول تجاری

| موضوع | کار |
|---|---|
| مقررات | بررسی با مشاور regulatory: آیا TGA این نرم‌افزار را Medical Device (SaMD) می‌داند؟ |
| حریم خصوصی | ارزیابی Privacy Act 1988 و APPs؛ سیاست نگهداری داده |
| Backend | حساب داروخانه، دستگاه‌ها، توزیع امن مدل (Model Registry)، پشتیبان Audit |
| اتصال | ورود پروفایل از نرم‌افزار بسته‌بندی (FRED، Minfos و…) به‌جای ورود دستی |
| امنیت | قفل اپ (Face ID/کد)، رمزگذاری Audit، تست نفوذ |
| انتشار | Apple Developer Program به نام شرکت، TestFlight، App Store یا توزیع Enterprise |
| کسب‌وکار | بیمه‌ی مسئولیت، قرارداد و شرایط استفاده، قیمت‌گذاری و پشتیبانی |

## ریسک‌های اصلی

1. **داده:** بدون دیتاست تأییدشده‌ی داروساز، هویت دارو ممکن نیست.
2. **False Acceptance:** هر قبول اشتباه ریسک بالینی دارد؛ به همین دلیل همه‌ی پیش‌فرض‌ها محافظه‌کارانه‌اند.
3. **مقررات:** طبقه‌بندی TGA می‌تواند زمان و هزینه‌ی ورود به بازار را تغییر دهد.
4. **مخزن عمومی:** این مخزن public است؛ برای محصول تجاری آن را private کنید.
