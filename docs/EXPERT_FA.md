# متخصص زبانی (Claude)

یک مدل زبانی تخصصی (Claude Opus 5.5 از Anthropic) سه کار انجام می‌دهد. هیچ‌کدام در مسیر قبول پک نیستند: Claude هرگز چیزی را قبول نمی‌کند، فقط می‌تواند هشدار بدهد یا کار داروساز را سریع‌تر کند.

| کار | ورودی | خروجی | effort |
|---|---|---|---|
| **خواندن لیست دارو** | PDF، عکس یا متن packing sheet | لیست ساختاریافته: نام، قدرت، دوز هر نوبت، روزها، موارد نامطمئن | `high` |
| **توضیح نتیجه** | یافته‌های موتور تصمیم (متن، نه عکس) | خلاصه و مراحل بررسی به انگلیسی یا فارسی | `low` (سریع) |
| **نظر دوم** | عکس صاف‌شده‌ی یک خانه + محتوای مورد انتظار | موافق / مخالف / مطمئن نیستم + تعداد | `medium` |

## قوانین ایمنی

- **خواندن لیست دارو:** Claude فقط متن را می‌خواند. تطبیق با کاتالوگ و چیدن در جدول ۷×۴ را کد قطعی انجام می‌دهد (`expert/charts.py`). هر تردید یک «issue» می‌شود:
  - دارویی که در کاتالوگ نیست یا چند تطبیق دارد ⇐ جای‌گذاری نمی‌شود تا داروساز انتخاب کند
  - نصف قرص ⇐ خودکار جای‌گذاری نمی‌شود
  - برنامه‌ی هفتگی بدون روز شروع پک ⇐ جای‌گذاری نمی‌شود
  - هر چیزی که Claude «نامطمئن» گزارش کرده
  - موارد غیرقابل بسته‌بندی (PRN، شربت، اسپری) جدا نشان داده می‌شوند

  نتیجه فقط یک **پیش‌نویس** است و تا داروساز آن را بررسی و ذخیره نکند استفاده نمی‌شود.
- **نظر دوم:** مخالفت ⇐ خانه به `needsReview` می‌رود (`core/advisory.py`). موافقت یا «مطمئن نیستم» هیچ تغییری نمی‌دهد. اگر Claude بگوید «درست است» ولی تعدادش با پروفایل فرق کند، مخالفت حساب می‌شود. همه‌ی نظرها در رکورد Audit ثبت می‌شوند.
- **توضیح:** فقط از یافته‌های موتور ساخته می‌شود و دستور دارد هیچ یافته‌ای را اضافه، حذف یا کم‌اهمیت نکند.

## جزئیات فنی

- SDK رسمی `anthropic` (Python)، مدل `claude-opus-5-5`، خروجی ساختاریافته (structured outputs) با Pydantic.
- **Fallback سمت سرور فعال است:** اگر طبقه‌بند ایمنی یک درخواست را رد کند، Anthropic همان درخواست را خودکار روی مدل جایگزین پیشنهادی اجرا می‌کند (`fallbacks: "default"`). در تنظیمات قابل خاموش کردن است. مدلی که واقعاً جواب داده در نتیجه ثبت می‌شود.
- رد شدن درخواست (`refusal`)، قطع جواب (`max_tokens`) و قطع اتصال، خطای روشن می‌دهند و ایستگاه بدون متخصص به کار ادامه می‌دهد.
- نظر دوم روی چند خانه موازی (۶ درخواست هم‌زمان) گرفته می‌شود. به‌طور پیش‌فرض فقط روی خانه‌هایی که موتور قبول کرده (چون فقط آنجا مخالفت چیزی را عوض می‌کند).

## کلید API

یکی از این‌ها:

1. Settings ← API key ← Store key (در Windows Credential Manager ذخیره می‌شود)
2. متغیر محیطی `ANTHROPIC_API_KEY`
3. `ant auth login`

کلید هرگز وارد Git نمی‌شود.

## هزینه (تقریبی)

قیمت Opus 5.5: ۴ دلار برای هر میلیون توکن ورودی و ۲۰ دلار برای خروجی.

| کار | تقریب هزینه |
|---|---|
| خواندن یک لیست دارو | چند سنت |
| توضیح یک نتیجه | کمتر از یک سنت |
| نظر دوم روی یک خانه | حدود ۲–۳ سنت؛ روی کل پک (۲۸ خانه) حدود ۰٫۷ دلار |

به همین دلیل نظر دوم دستی است (دکمه‌ی Second opinion)، نه خودکار.
