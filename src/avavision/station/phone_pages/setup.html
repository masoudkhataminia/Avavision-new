AvaVision iPhone camera

One-time setup. Safari lets a page use the camera only over a secure connection, so this iPhone must trust the station's own certificate first.

1. Download the station certificate
  1. Safari asks to download a configuration profile: tap Allow.
  2. Open Settings → Profile Downloaded (or General → VPN & Device Management) → AvaVision station → Install.
  3. Open Settings → General → About → Certificate Trust Settings and switch on AvaVision station (local network only).
  4. On the station computer, open Settings → iPhone camera and scan the Camera QR code with this iPhone's Camera app. Open the link in Safari.

This certificate can only vouch for addresses inside your local network, never for web sites. Its fingerprint (SHA-256) must match the one on the station's screen:
